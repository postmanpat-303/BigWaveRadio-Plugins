# Silence Skipper

Skips to the next station in your list after a stretch of dead air (20 seconds by default, adjustable from 5 to 120 in the plugin's panel).

| | |
| --- | --- |
| id | `silence-skip` |
| version | 1.0.0 |
| author | BigWave Radio examples |
| permissions | `audio`, `player_control`, `now_playing`, `panel` |

## Install

Download **[silence-skip.zip](https://github.com/postmanpat-303/BigWaveRadio-Plugins/releases/download/catalog/silence-skip.zip)**, then in BigWave Radio open **Plugins → Import .zip** (or drag the zip onto the window) and click **Allow & enable**.

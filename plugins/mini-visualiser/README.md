# Mini Visualiser

Adds a whole Visualiser page to the side bar: spectrum bars and a BPM readout.

A small example from the plugin guide: adds a **Visualiser** page to the side bar with spectrum bars and a BPM readout.

| | |
| --- | --- |
| id | `mini-visualiser` |
| version | 1.0.0 |
| author | BigWave Radio examples |
| permissions | `audio`, `page` |

## Install

Download **[mini-visualiser.zip](https://github.com/postmanpat-303/BigWaveRadio-Plugins/releases/download/catalog/mini-visualiser.zip)**, then in BigWave Radio open **Plugins → Import .zip** (or drag the zip onto the window) and click **Allow & enable**.

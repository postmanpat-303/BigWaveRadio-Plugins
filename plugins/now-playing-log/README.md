# Now Playing Log

Keeps a list of the last 15 songs heard, with the station name.

A small example from the plugin guide: a panel on the Plugins page listing the last 15 songs heard, with the station name.

| | |
| --- | --- |
| id | `now-playing-log` |
| version | 1.0.0 |
| author | BigWave Radio examples |
| permissions | `now_playing`, `panel`, `storage` |

## Install

Download **[now-playing-log.zip](https://github.com/postmanpat-303/BigWaveRadio-Plugins/releases/download/catalog/now-playing-log.zip)**, then in BigWave Radio open **Plugins → Import .zip** (or drag the zip onto the window) and click **Allow & enable**.

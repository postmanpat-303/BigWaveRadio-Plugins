# Bass Border

A glowing border that pulses with the bass, drawn in-window over the app.

A small example from the plugin guide: a border around the app window that pulses with the bass. No flashing: only the thickness changes.

| | |
| --- | --- |
| id | `bass-border` |
| version | 1.0.0 |
| author | BigWave Radio examples |
| permissions | `audio`, `overlay`, `hotkeys`, `panel` |

## Install

Download **[bass-border.zip](https://github.com/postmanpat-303/BigWaveRadio-Plugins/releases/download/catalog/bass-border.zip)**, then in BigWave Radio open **Plugins → Import .zip** (or drag the zip onto the window) and click **Allow & enable**.
